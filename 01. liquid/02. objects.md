# Shopify Liquid Objects

Q1. What is a Liquid Object?

Short Answer
A Liquid object contains data that we can access and display in a Shopify theme.

Example
{{ product.title }}
{{ product.price }}
{{ shop.name }}

Here:
- product = object
- title = property
- price = property
- shop = object
- name = property


========================================================================

Q2. What are the most important Shopify Liquid objects?

As a Shopify theme developer, the most important objects to understand are:

- product
- collection
- cart
- shop
- customer
- section
- settings
- request

You don't need to memorize every Shopify object. First become very comfortable with these.


=================================================================

Q3. What is the product object?

The product object represents a Shopify product.

Example:

- {{ product.title }}
- {{ product.vendor }}
- {{ product.description }}
- {{ product.url }}
- {{ product.handle }}


Common Product Properties

- {{ product.title }}
- {{ product.vendor }}
- {{ product.description }}
- {{ product.url }}
- {{ product.handle }}
- {{ product.type }}
- {{ product.featured_image }}
- {{ product.price }}
- {{ product.available }}

For example:

<h1>{{ product.title }}</h1>
<p>{{ product.vendor }}</p>
<p>{{ product.price | money }}</p>


Important
product can also contain variants, images, options, tags, collections, and other product-related data.


============================================================================

Q4. What is the collection object?

The collection object represents a Shopify collection.

Example:

- {{ collection.title }}
- {{ collection.description }}
- {{ collection.url }}
- {{ collection.handle }}


Most importantly:

- {{ collection.products }}

This gives us the products belonging to the collection.

Example:

{% for product in collection.products %}
  <h2>{{ product.title }}</h2>
{% endfor %}

This is commonly used on collection pages.


=====================================================================

Q5. What is the cart object?

The cart object contains information about the customer's current cart.

Examples:

- {{ cart.item_count }}
- {{ cart.total_price | money }}

To loop through cart items:

{% for item in cart.items %}
  <h3>{{ item.product.title }}</h3>
  <p>{{ item.quantity }}</p>
  <p>{{ item.final_line_price | money }}</p>
{% endfor %}


Commonly used for:

- Cart page
- Cart drawer
- Cart item count
- Cart total
- Cart items


=============================================================================

Q6. What is the shop object?

The shop object contains information about the Shopify store.

Examples:

- {{ shop.name }}
- {{ shop.url }}
- {{ shop.email }}

For example:

<footer>
  <p>{{ shop.name }}</p>
</footer>


=============================================================================

Q7. What is the customer object?

The customer object contains information about the logged-in customer.

Example:

{% if customer %}
  <p>Welcome, {{ customer.first_name }}</p>
{% else %}
  <a href="/account/login">Login</a>
{% endif %}

Important:

{% if customer %}

checks whether a customer is logged in.


============================================================

Q8. What is the section object?

The section object represents the current Shopify section.

It is extremely important when building customizable sections.

For example:

{{ section.settings.heading }}

If the schema contains:

{
  "type": "text",
  "id": "heading",
  "label": "Heading"
}

then:

{{ section.settings.heading }}

retrieves the value entered by the merchant in the Theme Editor.

Remember
section
   ↓
settings
   ↓
merchant's customization


====================================================================

Q9. What is the settings object?

settings gives access to theme settings.

For example:

{{ settings.logo }}
{{ settings.primary_color }}

These settings are generally defined in the theme's settings configuration.

This is useful for global things such as:

- Logo
- Colors
- Fonts
- Social links
- General theme settings

===============================================================================

Q10. What is the difference between section.settings and settings?

This is an important interview question.

section.settings

Used for settings belonging to a specific section.

{{ section.settings.heading }}
settings

Used for global theme settings.

{{ settings.logo }}
Easy way to remember
section.settings
        ↓
Specific section

settings
        ↓
Whole theme

=================================================================================

Q11. What is a product variant object?

A variant represents a specific version of a product.

For example:

T-Shirt
 ├── Small / Black
 ├── Medium / Black
 ├── Large / Black
 ├── Small / White
 └── Medium / White

Each variant can have its own:

ID
Price
SKU
Availability
Inventory
Image

Example:

{{ product.selected_or_first_available_variant.id }}
{{ product.selected_or_first_available_variant.price | money }}
{{ product.selected_or_first_available_variant.sku }}

This is extremely important for product pages and Add to Cart functionality.


======================================================================================

Q12. What is the difference between product.price and variant price?

product.price represents the product's price based on Shopify's product pricing behavior, while a specific variant has its own price.

When working with a selected variant, you should work with the variant object.

Example:

{{ product.selected_or_first_available_variant.price | money }}

This becomes especially important when implementing JavaScript variant selection.


================================================================================

Q13. How do you access an object inside another object?

Liquid objects can contain other objects.

Example:

{{ product.selected_or_first_available_variant.sku }}

Here:

product
   ↓
selected_or_first_available_variant
   ↓
sku

Another example:

{{ cart.items[0].product.title }}


======================================================================

Q14. How do you access a collection by handle?

You can access a collection using its handle:

{% assign featured_collection = collections['featured'] %}

Then:

{{ featured_collection.title }}

And:

{% for product in featured_collection.products %}
  {{ product.title }}
{% endfor %}

This is useful when you need to work with a specific collection.

# Interview Question

"What Shopify Liquid objects do you commonly use?"

Strong Answer

The objects I commonly use are product, collection, cart, customer, shop, section, and settings. For example, I use the product object for product information and variants, collection for product listings, cart for cart data, section.settings for section-specific Theme Editor settings, and settings for global theme configuration.
