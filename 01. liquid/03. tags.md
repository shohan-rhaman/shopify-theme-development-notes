# Shopify Liquid Tags

Q1. What is a Liquid tag?

Short Answer
A Liquid tag controls the logic or execution of a Shopify theme.

Unlike {{ }}, which outputs a value, {% %} is used to perform an action or logic.

Example:

{% if product.available %}
  <button>Add to Cart</button>
{% endif %}


==========================================================================

Q2. What are the most commonly used Liquid tags?

The most important tags for Shopify theme development are:

- if
- unless
- elsif
- else
- for
- case
- assign
- capture
- render
- paginate
- comment

You don't need to memorize every Liquid tag immediately. Master these first.


================================================================

Q3. How does if work?

if executes code when a condition is true.

{% if product.available %}
  <button>Add to Cart</button>
{% endif %}

You can also use else:

{% if product.available %}
  <button>Add to Cart</button>
{% else %}
  <button disabled>Sold Out</button>
{% endif %}

==================================================================================

Q4. How do you use elsif?

elsif allows you to check another condition.

{% if product.available %}
  Available
{% elsif product.tags contains 'coming-soon' %}
  Coming Soon
{% else %}
  Sold Out
{% endif %}

The conditions are checked from top to bottom.


==================================================================

Q5. What is unless?

unless is basically the opposite of if.

{% unless product.available %}
  <span>Sold Out</span>
{% endunless %}

This means:

Show "Sold Out" unless the product is available.

You can use either if or unless, but if is generally easier to understand for complex conditions.


================================================================================

Q6. How does the for loop work?

for repeats code for every item in a collection.

Example:

{% for product in collection.products %}
  <h2>{{ product.title }}</h2>
{% endfor %}

This is extremely common in:

- Collection pages
- Product grids
- Related products
- Navigation
- Cart items

======================================================================
Q7. What is forloop?

forloop provides information about the current loop.

Example:

{% for product in collection.products %}
  <p>{{ forloop.index }}. {{ product.title }}</p>
{% endfor %}

Useful properties include:

- forloop.index
- forloop.index0
- forloop.first
- forloop.last
- forloop.length

Example
{% if forloop.first %}
  First Product
{% endif %}


================================================================================

Q8. How do you limit the number of items in a loop?

You can use the limit parameter.

{% for product in collection.products limit: 4 %}
  {{ product.title }}
{% endfor %}

This displays only the first 4 products.

You can also use offset:

{% for product in collection.products limit: 4 offset: 4 %}
  {{ product.title }}
{% endfor %}

This skips the first 4 and displays the next 4.


========================================================

Q9. What is assign?

assign creates a Liquid variable.

{% assign featured_collection = collections['featured'] %}

Now you can use:

{{ featured_collection.title }}

Another example:

{% assign product_title = product.title %}

Then:

{{ product_title }}
Why use it?

It makes code easier to reuse and sometimes easier to understand.


============================================================================

Q10. What is capture?

capture stores generated Liquid/HTML output inside a variable.

Example:

{% capture product_label %}
  {{ product.vendor }} - {{ product.title }}
{% endcapture %}

Then:

{{ product_label }}

Output might be:

Nike - Air Max
Difference from assign

assign stores a value:

{% assign title = product.title %}

capture stores rendered content:

{% capture label %}
  {{ product.vendor }} - {{ product.title }}
{% endcapture %}

You will use assign much more frequently in normal theme development.


=================================================================

Q11. What is render?

render loads a Shopify snippet.

Example:

{% render 'product-card', product: product %}

Here:

product-card
     ↓
snippet file
     ↓
snippets/product-card.liquid

The product object is passed into the snippet.

Inside the snippet:

<h2>{{ product.title }}</h2>

This is one of the most important concepts for creating reusable Shopify themes.


======================================================================

Q12. Why use render instead of duplicating code?

Imagine you have a product card on:

Homepage
Collection page
Search page
Related products
Featured products

Instead of writing the same product-card HTML five times, create one snippet:

snippets/product-card.liquid

Then:

{% render 'product-card', product: product %}

This gives you:

Reusable code
Easier maintenance
Consistent UI
Less duplication

==============================================================

Q13. What is case?

case is useful when you have multiple possible values.

Example:

{% case product.type %}
  {% when 'T-Shirt' %}
    Clothing
  {% when 'Shoes' %}
    Footwear
  {% when 'Bag' %}
    Accessories
  {% else %}
    Other
{% endcase %}

It is similar to a switch statement in JavaScript.



==============================================================

Q14. What is paginate?

paginate is used to divide large collections of Shopify resources into pages.

Example:

{% paginate collection.products by 12 %}

  {% for product in collection.products %}
    {{ product.title }}
  {% endfor %}

{% endpaginate %}

This allows you to display 12 products per page.

Pagination is very important for collection and search pages.


=================================================

Q15. What is a Liquid comment?

You can temporarily disable or document Liquid code using:

{% comment %}
  This code will not be rendered.
{% endcomment %}

The comment isn't sent as normal page output.


================================================================

Q16. How do you combine multiple conditions?

You can use and and or.

Example:

{% if product.available and product.price > 5000 %}
  Premium Product
{% endif %}

Another example:

{% if product.available or product.tags contains 'preorder' %}
  Show Product
{% endif %}

Be careful with complicated conditions. If the logic becomes difficult to understand, simplify it or use variables.


===============================================================================

Q17. How do you check whether an array contains a value?

Use contains.

Example:

{% if product.tags contains 'sale' %}
  <span>Sale</span>
{% endif %}

This is commonly used for:

Product tags
Navigation values
Filtering logic
Conditional badges

==================================================================

Q18. What is the difference between Liquid tags and filters?

This is a common interview question.

Tag

Controls logic or performs an action:

{% if product.available %}
Filter

Modifies a value:

{{ product.title | upcase }}
Remember
Tag    → controls what happens
Filter → changes the value
Object → provides the data

Interview Questions You Should Know
Q: What is the purpose of assign?

Answer:

assign creates a Liquid variable that can store a value and be reused within the template.

==============================================================
Q: What is the purpose of render?

Answer:

render is used to include a reusable Shopify snippet and optionally pass variables or objects to that snippet.

====================================================================

Q: What is the difference between if and unless?

Answer:

if executes code when a condition is true, while unless executes code when a condition is false.
